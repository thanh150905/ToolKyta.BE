# docs/bmw-api — Tài liệu API backend (BA gửi) cho tích hợp luồng BMW cũ

Nơi lưu tài liệu backend do BA gửi để tích hợp API vào các luồng BMW cũ.

- `raw/`     — file gốc BA gửi, để nguyên (PDF/docx/xlsx/ảnh). KHÔNG sửa.
- `postman/` — Postman collection + environment (.json) để test endpoint.
- Đặc tả đã chuẩn hoá (endpoint, request/response, auth, mapping field) ghi
  thẳng vào file `<ten-api>.md` trong thư mục này.

Form/subform đích của BMW ở `workspace/bmw/`. Spec nghiệp vụ ở `docs/bmw-define/`.
